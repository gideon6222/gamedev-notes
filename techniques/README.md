# techniques/

Deep, game-specific technical write-ups pulled out of `CRAFT.md` and `PIPELINE.md`, one file per technique. Each starts with the game, its status, a "read when" trigger, a one-paragraph intro and two or three generalisable takeaways; the body is the original text, lightly edited for standalone reading. The general rules distilled from these live in the topic files — come here when you are about to build the same kind of thing and want the arithmetic, the constants and the dead ends.
