# techniques/

Deep technical write-ups pulled out of `CRAFT.md` and out of the old single pipeline file, archived on 2026-09-09 as `archive/PIPELINE-2026-09-09.md` and `WEB.md`. Most files here are game-specific; a few (`generated-audio`, `human-bot-policies`, `three-js-traps`, `three-js-renders-as-nothing`, `three-js-materials-and-lights`, `phone-camera-and-light`, `diagnosis-and-rework`, `filming-a-run`, `pixel-and-model-assertions`, `phone-layout-and-safe-area`, `build-output-and-the-package`) are cross-game. One file per technique. Each starts with the game, its status, a "read when" trigger, a one-paragraph intro and two or three generalisable takeaways; the body is the original text, lightly edited for standalone reading. The general rules distilled from these live in the topic files — come here when you are about to build the same kind of thing and want the arithmetic, the constants and the dead ends.
