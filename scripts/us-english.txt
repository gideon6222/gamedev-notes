# The studio's British-to-American word list. One `british=american` pair per line,
# lower case, `#` starts a comment, blank lines ignored. Whole words only: the doctor's
# Test-USEnglish builds a `\b<british>\b` pattern per pair and matches case-insensitively,
# so `Colour` and `COLOUR` are caught and `discolouration` is not (add the exact word if
# you want it).
#
# This file is the single source of truth. INDEX.md standing rule 15 states the rule,
# skills\digest\SKILL.md points a fold at this list, and scripts\doctor.ps1 reads it. If a
# word is missing, add it here and every one of those learns it at once.
#
# What must NEVER go in this list:
#
# - `dialogue`. American usage keeps `dialogue` for words two characters say to each other
#   and uses `dialog` only for a UI box. One spelling cannot be right for both, so a pair
#   here would rewrite the conversation kind every time.
# - Any word that is only ever an identifier: a shader uniform, a dictionary key, a JSON
#   field from somebody else's API, a Godot property name, a class name. The rule is about
#   what Gideon and a player read, not about what a machine parses. The check already
#   skips scripts\, addons\ and assets\CREDITS.md for that reason, but a word that can
#   only ever be an identifier does not belong here at all.
# - Quoted third-party licence text. Left as its author wrote it; that quote is evidence.
# - Anything where the two spellings mean different things in American English
#   (`practise`/`practice` is safe because American English has only `practice`, but check
#   before adding a new one).
